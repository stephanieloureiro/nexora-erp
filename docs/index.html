Modulos principais

Clientes

Cadastro, atualizacao, pesquisa, validacao de documento e inativacao logica.

Produtos

SKU unico, preco com BigDecimal, controle de estoque minimo e status ativo.

Estoque

Movimentacoes de entrada e saida com regras para bloquear saldo insuficiente.

Pedidos

Criacao, confirmacao, cancelamento, calculo de totais e integracao com estoque.

Seguranca

Login JWT, usuarios internos, BCrypt e permissoes para ADMIN e EMPLOYEE.

Relatorios e auditoria

Resumo de vendas, ranking de produtos, indicadores de estoque e eventos auditaveis.

Arquitetura

Back-end estruturado para portfolio profissional

O projeto usa arquitetura em camadas com controllers, services, repositories, entidades, DTOs, mappers, excecoes centralizadas e migracoes Flyway.

  • Java 21
  • Spring Boot 4.1
  • Spring Data JPA
  • PostgreSQL e H2
  • Flyway
  • Spring Security e JWT
  • OpenAPI e Swagger
  • GitHub Actions

Como usar

Executar o sistema completo

git clone https://github.com/stephanieloureiro/nexora-erp.git
cd nexora-erp
.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=local

Depois acesse http://localhost:8080/ e entre com admin@nexora.com / nexora123.
